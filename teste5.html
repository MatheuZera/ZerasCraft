BAIXAR O SERVIDOR MINECRAFT: JAVA EDITION

Deseja instalar um servidor multiplayer?

Observe que: Essa configuração de servidor só é compatível com o Minecraft: Java Edition.

Caso queira executar um servidor multiplayer do Minecraft por conta própria, o processo é um pouco mais complicado (consulte este artigo tutorial na wiki). Primeiro, verifique se você pode usar o Java a partir da linha de comando. No Linux e no macOS, essa configuração já deve estar definida, mas no Windows, talvez seja preciso mexer com a variável de ambiente PATH.

Baixe e execute minecraft_server.26.3.jar com o seguinte comando:

java -Xmx4G -Xms4G -jar minecraft_server.26.3.jar nogui

Se você quiser iniciar o servidor com a interface gráfica de usuário do próprio servidor, pode desconsiderar a parte "nogui".

Lembre-se de que, ao baixar qualquer software desta página, você concorda com o Contrato de Licença de Usuário Final do Minecraft e com a Política de Privacidade.

Caso queira ignorar a instalação e começar a explorar outros servidores de terceiros, visite nosso Site de lista de Servidores oficial. Cada servidor oferece o próprio estilo de diversão e exclusividade. Encontre o seu favorito no nosso Site de lista de servidores, no qual todos os servidores listados foram analisados e verificados e seguem nossos padrões e diretrizes da comunidade. Pesquise servidores com base no tipo e estilo de jogo, e muito mais. Provavelmente há um servidor listado para você, independentemente da sua idade ou da maneira como você joga.
